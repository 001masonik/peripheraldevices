### 1.Типи та характеристики SSD-накопичувачів

---

### 1. Що таке SSD

**SSD (Solid State Drive)** — це твердотільний накопичувач даних, який використовує флеш-пам’ять NAND для зберігання інформації.

На відміну від HDD, SSD:
- не має рухомих частин;
- працює швидше;
- не створює шуму;
- більш стійкий до механічних пошкоджень.


---

### 2. Будова SSD
Основні компоненти SSD:

1. **Контролер** — керує процесами читання та запису.
2. **Мікросхеми NAND-пам’яті** — зберігають дані.
3. **Кеш-пам’ять (DRAM або SLC-кеш)** — прискорює роботу накопичувача.
4. **Інтерфейс підключення** — SATA або PCIe.

## 3. Типи SSD за форм-фактором

### 2.5" SATA SSD

Найпоширеніший формат.

**Характеристики:**
- Інтерфейс: SATA III (6 Гбіт/с)
- Швидкість читання: до 550 МБ/с
- Швидкість запису: до 500 МБ/с
- Просте встановлення

---

### M.2 SATA SSD

Компактний формат у вигляді плати.

**Особливості:**
- Працює через SATA
- Не потребує кабелів
- Швидкість як у 2.5" SATA

![alt](https://serverparts.com.ua/image/cache/webp/catalog/content/ssd/SVM2SH6D120GL-400x500.webp "ssdm2")

---

### M.2 NVMe SSD

Найшвидший сучасний тип SSD.

**Характеристики:**
- Інтерфейс: PCIe (3.0 / 4.0 / 5.0)
- Протокол: NVMe
- Швидкість читання: 2000–14000 МБ/с
- Висока продуктивність

## 4. Типи пам’яті NAND

### SLC (Single-Level Cell)
- 1 біт на комірку
- Найшвидша та найдовговічніша
- Висока ціна

### MLC (Multi-Level Cell)
- 2 біти на комірку
- Баланс ціни та продуктивності

### TLC (Triple-Level Cell)
- 3 біти на комірку
- Найпоширеніший тип
- Доступна ціна

### QLC (Quad-Level Cell)
- 4 біти на комірку
- Найдешевший
- Менша довговічність

---

### 5. Основні характеристики SSD

### Об’єм
- 120 ГБ
- 240–256 ГБ
- 480–512 ГБ
- 1 ТБ
- 2 ТБ і більше

### Швидкість

- SATA: до 550 МБ/с
- NVMe PCIe 3.0: до 3500 МБ/с
- NVMe PCIe 4.0: до 7000 МБ/с
- NVMe PCIe 5.0: понад 10000 МБ/с

### 5.4 TBW (Total Bytes Written)

Загальний ресурс запису накопичувача.  
Наприклад, 300 TBW означає можливість запису 300 ТБ даних.

### 6. Переваги SSD

- Висока швидкість роботи
- Швидке завантаження системи
- Безшумність
- Низьке енергоспоживання
- Стійкість до ударів

### 7. Недоліки SSD

- Вища ціна за 1 ГБ
- Обмежений ресурс перезапису
- Може знижуватись швидкість при заповненні

## 8. Порівняння SSD та HDD

| Параметр | SSD | HDD |
|----------|------|------|
| Швидкість | Дуже висока | Низька |
| Шум | Відсутній | Є |
| Надійність | Вища | Нижча |
| Механічні частини | Немає | Є |
| Ціна за 1 ГБ | Вища | Нижча |

---

## 9. Висновок

SSD — це сучасний стандарт зберігання даних.  
Для звичайного використання підійде SATA або NVMe PCIe 3.0.  
Для ігор та професійної роботи — NVMe PCIe 4.0 або 5.0.

### Script PowerShell
```
# Set output encoding to UTF8 to handle all characters correctly
[Console]::OutputEncoding = [System.Text.Encoding]::UTF8

# Get all physical disks and sort them by ID
$disks = Get-PhysicalDisk | Sort-Object DeviceId

foreach ($d in $disks) {
    # Retrieve reliability counters (SMART data equivalent)
    $rel = Get-StorageReliabilityCounter -PhysicalDisk $d
    $healthColor = if ($d.HealthStatus -eq 'Healthy') { 'Green' } else { 'Red' }
    
    Write-Host "`n>>> DISK #$($d.DeviceId): $($d.FriendlyName)" -ForegroundColor Yellow
    Write-Host "---------------------------------------------------"
    Write-Host "Model:        $($d.Model)"
    Write-Host "Firmware:     $($d.FirmwareVersion)"
    Write-Host "Serial:       $($d.SerialNumber.Trim())"
    Write-Host "Bus Type:     $($d.BusType) (PCIe)"
    Write-Host "Size:         $([math]::Round($d.Size/1GB, 2)) GB"
    Write-Host -NoNewline "Status:       "; Write-Host $d.HealthStatus -ForegroundColor $healthColor
    
    if ($rel) {
        Write-Host "---------------- DETAILED SMART -------------------"
        
        # Monitor Temperature
        if ($rel.Temperature) {
            $t = $rel.Temperature
            $tc = if ($t -lt 50) {'Green'} elseif ($t -lt 60) {'Yellow'} else {'Red'}
            Write-Host "Temperature:    $t C" -ForegroundColor $tc
        }
        
        # Calculate Operational Time
        if ($rel.PowerOnHours -ne $null) {
            $hours = $rel.PowerOnHours
            Write-Host "Power-on Time:  $hours hours ($([math]::Round($hours/24, 1)) days)"
        }
        
        # Calculate Host Writes and Reads in TB
        $tbw = [math]::Round($rel.TotalBytesWritten/1TB, 3)
        $read = [math]::Round($rel.TotalBytesRead/1TB, 3)
        Write-Host "Total Written:  $tbw TB"
        Write-Host "Total Read:     $read TB"
        
        # Display SSD Wear level
        if ($rel.Wear -ne $null) {
            Write-Host "SSD Wear:       $($rel.Wear) %" -ForegroundColor Cyan
        }

        # Check for Critical Alarms
        if ($rel.CriticalAlarms -and $rel.CriticalAlarms -ne 0) {
            Write-Host "WARNING: Critical alarms detected!" -ForegroundColor Red
        }
    }
    Write-Host "---------------------------------------------------"
}
```
