### 1. Огляд та характеристики слотів розширення (expantion slots) на материнській платі

#### Слоти розширення (expansion slots) на материнській платі — це роз’єми (переважно PCIe), призначені для встановлення додаткових модулів, що розширюють можливості ПК (відеокарти, звукові/мережеві карти, SSD). Основні типи: PCIe x16 (для відеокарт) та PCIe x1/x4 (для периферії). Сучасні плати підтримують інтерфейс PCIe 5.0/4.0, забезпечуючи високу швидкість обміну даними. 

### **Основні види та характеристики слотів розширення**

### PCI - Peripheral Component Interconnect
![alt](https://upload.wikimedia.org/wikipedia/commons/6/67/PCI_Slots_Digon3.JPG "PCI")

(роз’єм взаємодії периферійних компонентів) – 32- або 64-розрядний слот розширення. В даний час він зустрічається в декількох комп’ютерах. Слоти розширення PCI здебільшого застаріли.

##

### Mini PCI - Mini Peripheral Component Interconnect
![alt](https://rene.seindal.dk/linux-upload/2007/03/20041027-pa260006.jpg "minipci" )

Це менша версія PCI використовується в деяких ноутбуках. Міні PCI має три різних форм-фактора: Тип I, Тип II і Тип III.

##

### Pci-X Peripheral Component Interconnect eXtended

![alt](https://upload.wikimedia.org/wikipedia/commons/6/66/ZRAID_at_PCI-X_at_FSC_Primtrgy_TX200_S2.JPG "pcix" )

Це оновлена версія стандарту PCI. Він використовує 32-розрядну шину з більшою пропускною здатністю, ніж шина PCI. PCI-X може працювати в чотири рази швидше, ніж PCI. Слоти розширення PCI-X здебільшого застаріли.

##

### PCIe - Peripheral Component Interconnect xpress

![alt](https://www.lifewire.com/thmb/4gLvZyjVNRPigzWoJbk3YoQtkWU=/1500x0/filters:no_upscale():max_bytes(150000):strip_icc()/pci-express-pcie-2625962-79f643e7768d4b8e81e2eee6cf5b02e7.png "pcie" )

PCI Express використовує послідовну шину, яка має більш високу пропускну здатність і багато інших удосконалень у порівнянні зі старими слотами розширення. PCIe має слоти x1, x4, x8 і x16, які відрізняються довжиною від найкоротшого до найдовшого відповідно. Тут наведено два найпоширеніших розмірів, x1 вгорі і x16 внизу.

### Riser card - Перехідник/розширювач, допоміжний елемент.

![alt](https://content.rozetka.com.ua/goods/images/big/619209129.jpg "rasercard" )

Плата Riser може бути додана на комп'ютер, щоб забезпечити додаткові слоти розширення для більшої кількості плат розширення.

##
### AGP - Accelerated Graphics Port, прискорений графічний роз'єм

![alt](https://upload.wikimedia.org/wikipedia/commons/0/08/AGP_at_ECS_P4VMM2.JPG "agp" )

Прискорений графічний порт (AGP) - високошвидкісний слот для підключення відеокарти AGP. AGP був замінений PCI. Небагато материнських плат досі використовують цю технологію.

##

### 2. Карти розширення (expantion cards) на інтерфейсі PCI-e (8 шт. для різних типів слотів)

### Відеокарта (GPU) — слот x16

![alt](https://mobileplanet.ua/uploads/small_photos/2025-5-6/gigabyte-geforce-rtx-5060-ti-gaming-oc-16gb-gddr7-342538_1.webp "gpu" )

Найпоширеніша карта для роз'єму PCIe x16. Вона потребує максимальної пропускної здатності для передачі графічних даних між процесором та відеопам'яттю. Сучасні карти підтримують стандарти PCIe 4.0 та 5.0.

### Мережевий адаптер Ethernet (10 Gbps) — слот x4 або x8

![alt](https://dtcgroup.com.ua/uploads/products/Media%20Converter/P8-10G-4S/pcie-v3-x8-10g-four-ports-server-ethernet-adapter-p8-10g-4s-4.webp "eth" )

Хоча звичайні гігабітні карти працюють на x1, потужні серверні рішення або адаптери на 10/25 Гбіт/с потребують слотів x4 або x8, щоб уникнути обмежень швидкості передачі даних.

### Звукова карта — слот x1

![alt](https://frime.ua/image/cache/catalog/zvukovye-karty/SCF-CMI8738-4CH.LP/SCF_CMI8738_4CH.LP_1-1502x1336.jpg "eth" )

Професійні або геймерські аудіокарти (наприклад, серії ASUS Essence або Creative Sound Blaster) зазвичай використовують найкоротший слот x1, оскільки передача аудіосигналу не потребує великої пропускної здатності.

### Адаптер для NVMe SSD (M.2 Expansion Card) — слот x4 або x16

![alt](https://img.joomcdn.net/d627e8bdf24a84768204960f68e5bbd360fdba35_1024_1024.jpeg "ada" )

Якщо на материнській платі закінчилися роз'єми M.2, можна використовувати карту-перехідник. Прості адаптери на один диск ставляться в x4, а масивні карти (quad-adapters) на 4 диски потребують x16 з підтримкою біфуркації (розподілу ліній).

### Контролер USB 3.2 / USB-C — слот x1 або x4

![alt](https://www.equip-info.net/media/catalog/product/cache/5dd1050e303ccd126a15d8279a1aa7f2/c/5/c564c9d56d9e244657e14ef2e9be75f5f95832c2_EMRICK09G_V1_product_01_high_1.jpg "ada" )

Використовується для додавання додаткових швидкісних портів на задню панель ПК. Карти з декількома портами USB-C 20Gbps зазвичай потребують слота x4 для повноцінної роботи всіх роз'ємів одночасно.

### Карта захоплення відео (Capture Card) — слот x1 або x4

![alt](https://content.rozetka.com.ua/goods/images/big_tile/398808758.jpg "cc" )

Незамінний інструмент для стримерів. Карти для запису Full HD відео часто використовують x1, тоді як сучасні моделі для 4K/60fps потребують x4.

### RAID-контролер — слот x8

![alt](https://server-shop.ua/assets/images/resources/4720/hp-smart-array-p420.png "raid" )

Використовується в серверах та робочих станціях для об'єднання великої кількості жорстких дисків у надійні масиви. Більшість професійних контролерів (LSI, Broadcom) розраховані саме на слот x8.

### Wi-Fi / Bluetooth адаптер — слот x1

![alt](https://content.rozetka.com.ua/goods/images/big_tile/396832998.jpg "wb" )

Маленька карта, що додає бездротовий зв'язок. Більшість сучасних модулів стандарту Wi-Fi 6E або Wi-Fi 7 використовують інтерфейс x1, оскільки навіть їхньої швидкості (до 5-9 Гбіт/с) достатньо для цього ліміту (особливо в поколінні PCIe 3.0+).

| Тип слота | Кількість контактів (приблизно) | Основне призначення                         |
|------------|----------------------------------|--------------------------------------------|
| x1         | 36                               | Звук, Wi-Fi, прості контролери             |
| x4         | 64                               | SSD адаптери, карти захоплення 4K          |
| x8         | 98                               | RAID-контролери, мережеві карти 10G+       |
| x16        | 164                              | Відеокарти, масиви NVMe SSD                |
